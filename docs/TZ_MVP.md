# Техническое задание (MVP)

## 1. Введение

### 1.1 Назначение системы

Веб-приложение для групп поклонения, позволяющее:

- хранить песни и плейлисты внутри групп;
- управлять мультитрек-плейбеками;
- воспроизводить плейбеки в вебе и через нативный агент-плеер;
- готовить и проигрывать сет-листы;
- использовать режим сцены;
- общаться через встроенный чат.

### 1.2 Диапазон применения

MVP рассчитан на 1--2 группы, до 100 пользователей, до 6 агентов,
развёртывание на серверах заказчика.

## 2. Основные сущности

### 2.1 Пользователь

- Регистрация email+пароль через Keycloak.
- Может состоять в нескольких группах.
- Приглашение принимается только зарегистрированным пользователем.

### 2.2 Группа

- Изолированная библиотека песен, плейлистов и плейбеков.
- Несколько агентов-плееров, привязанных токеном.

### 2.3 Песня

Поля: - название; - автор; - текст; - аккорды; - тональность; - BPM.

### 2.4 Плейлист (сет-лист)

- упорядоченный список песен;
- длительность;
- блоки/паузы;
- комментарии;
- собственная тональность для каждой песни в рамках сет-листа.

### 2.5 Плейбек

- один мультитрек на песню;
- хранение в MinIO;
- несколько дорожек;
- микшер громкости;
- пресеты.

## 3. Пользовательские сценарии

### 3.1 Регистрация

Через Keycloak, свободная.

### 3.2 Группы

Создание, просмотр, переключение, управление участниками (по
пермишенам).

### 3.3 Приглашения

- По email.
- По одноразовой ссылке.

### 3.4 Песни

CRUD, поиск.

### 3.5 Плейлисты

CRUD, тональности для контекста, блоки.

### 3.6 Плейбеки

Загрузка, редактирование, микшер, пресеты.

### 3.7 Чат

Текст + голосовые сообщения.

### 3.8 Уведомления

Внутренние уведомления без Web Push.

### 3.9 Stage Mode

Полноэкранный режим отображения текста и аккордов.

## 4. Агент-плеер

### 4.1 Платформы

Windows, macOS.
Console.

### 4.2 Функции

- Привязка к группе по токену.
- Несколько агентов на группу.
- Управление только из веба.
- gRPC streaming/WebSocket.
- Передаёт состояние (позиция, загрузка, ошибки).

## 5. Офлайн-режим

### 5.1 Данные

Песни, сет-листы, аудио.

### 5.2 Механика

Ручная загрузка. Проверка новых версий при подключении.

## 6. Пермишены

- Управление участниками.
- Редактирование песен.
- Редактирование плейлистов.
- Управление плейбеками.
- Управление агентом.

## 7. Поиск

Общая строка поиска по песням и плейлистам.

## 8. Архитектура и стек

- Frontend: React + TS + Vite + TailwindCSS + ShadcnUI.
- Backend: ASP.NET Core + .NET 10.0.
- Auth: Keycloak.
- DB: MongoDB.
- File Storage: MinIO (S3).
- WebSocket (SignalR) + REST.
- Агент: кроссплатформенный (Win/macOS) console app.

## 9. Нефункциональные требования

### 9.1 Производительность

100 пользователей, 2 группы, 6 агентов.

### 9.2 Безопасность

JWT, HTTPS/WSS.
Keycloak.

## 10. Тестирование

Модульное, интеграционное, E2E.
