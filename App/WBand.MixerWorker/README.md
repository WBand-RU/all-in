# MixerWorker

Запускается через Aspire AppHost как `mixer-worker`. Использует PostgreSQL и RustFS;
для рендеринга на машине запуска должен быть доступен `ffmpeg`.

Quartz каждые пять секунд выбирает задания `MixBatch` из PostgreSQL. От одновременной
обработки несколькими worker защищают PostgreSQL session advisory lock и optimistic
concurrency. Блокировка удерживается отдельным непулируемым соединением; после
остановки worker освобождается сразу, без ожидания тридцатиминутной аренды. Потеря
соединения отменяет рендеринг, а остановка приложения возвращает задание в очередь.

Для каждого инструментального стема создаются Focus и Minus; Click и Guide остаются
в миксах, но не создают собственных вариантов. 21 стем с Click и Guide даёт 38 миксов.
WAV и MP3 — два формата одного микса: прогресс увеличивается после сохранения обоих.
Полный микс из старых заданий не включается в этот счётчик и список вариантов.

После перезапуска уже сохранённые артефакты не рендерятся повторно. Документы новых
артефактов имеют детерминированные идентификаторы. Исходники кэшируются в рабочем
каталоге и перед повторным использованием проверяются по размеру и SHA-256.
Скачивание имеет максимум три попытки по две минуты; временные сбои задания
повторяются до пяти раз с задержкой. Рендеринг одной группы ограничен десятью
минутами. Неустранимая ошибка переводит задание в Failed с описанием причины.

Wolverine работает в режиме `DurabilityMode.MediatorOnly`: worker вызывает
обработчики FileModule и StemModule синхронно через `IMessageBus.InvokeAsync`.
Фоновые messaging-агенты и выбор лидера здесь не нужны; долговечность очереди
миксов обеспечивает `MixBatch`, а не inbox/outbox Wolverine. Интеграция с Marten
сохраняется для разрешения сессий базы в обработчиках. Асинхронные события системы
обрабатывает WebAPI.

Обязательная конфигурация передаётся AppHost: `MARTEN_DATABASE_CONNECTION_STRING`,
`MARTEN_DATABASE_SCHEMA_NAME`, `S3_HOST`, `S3_BUCKET`, `S3_ACCESS_KEY`,
`S3_SECRET_KEY`, `S3_UPLOAD_EXPIRATION_SECONDS`, `S3_DOWNLOAD_EXPIRATION_SECONDS`.
