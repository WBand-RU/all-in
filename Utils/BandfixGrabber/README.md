# BandfixGrabber

Скачивает все доступные неудалённые песни **MBV Youth** из Bandfix в отдельные JSON-файлы. Сохраняет полные ответы API: тексты, аккорды, метаданные и ссылки на вложения. Сами медиафайлы не скачивает.

## Запуск

Из корня репозитория:

```bash
dotnet run --project Utils/BandfixGrabber
```

Нужны .NET 10 и установленный Google Chrome. Playwright используется для подключения к обычному Chrome; отдельно устанавливать Chromium через Playwright не требуется.

Утилита сама открывает обычный Chrome с отдельным профилем `Utils/BandfixGrabber/chrome-profile`. Если необходим вход, выберите Google и аккаунт `igorock4jesus@gmail.com`. **Не закрывайте окно после входа**: утилита проверит доступ к группе и автоматически начнёт скачивание в том же сеансе.

Используется установленный Chrome без флагов автоматизации Playwright. Это устраняет прежний запуск входа в автоматизированном Chromium, но решение о разрешении Google-входа остаётся за Google. Пароли и коды в консоль вводить не нужно.

Пустой список групп и HTTP 401/403 во время входа не прерывают ожидание: утилита ждёт обновления сессии до 10 минут. Сессии Google и Bandfix могут быть разными; сам по себе успешный вход на странице Google ещё не подтверждает доступ к группе в Bandfix.

Chrome остаётся открытым после завершения. Повторный запуск подключается к этому же отдельному браузеру. Для обнаружения используются сохранённый адрес, файл Chrome `DevToolsActivePort`, а на Linux также порт процесса, владеющего блокировкой этого профиля. Это поддерживает и окна, открытые предыдущей версией утилиты с фиксированным портом. Новый Chrome выбирает свободный порт самостоятельно (`--remote-debugging-port=0`). Если Chrome закрыт, запускается заново с сохранённым профилем. Основной профиль Chrome не используется. При подключении к существующей вкладке сохраняется её домен (`bandfix.by` или `bandfix.app`).

## Результат

По умолчанию: `Utils/BandfixGrabber/songs/`.

- Один JSON с исходными данными на каждую песню. Имена файлов — ID, закодированные в hex; это исключает конфликты названий и небезопасные символы путей.
- `_manifest.json`: группа, время выгрузки, число найденных и сохранённых песен, соответствие ID → файл, ошибки и признак `complete`.
- Код завершения `0`: все найденные песни сохранены; `1`: ошибка или неполная выгрузка; `130`: отмена через Ctrl+C.

Группа выбирается по списку групп текущего аккаунта. Пробелы, `_` и `-` при сравнении имён игнорируются: `MBV Youth` соответствует `MBV_Youth`. При неоднозначном совпадении выгрузка останавливается. Все запросы списка песен используют ID выбранной группы, независимо от группы, открытой в интерфейсе.

Список читается по всем страницам `x-cursor`, дубликаты ID исключаются, детали каждой песни загружаются отдельным запросом. Повторившийся курсор считается ошибкой. HTTP 429 и 5xx повторяются до четырёх раз с задержкой; поддерживается `Retry-After`. При обновлении токена в браузере следующие запросы используют новый токен. При ошибке отдельной песни остальные сохраняются, но manifest получает `complete: false`.

Повторный запуск перезаписывает соответствующие JSON. Старые файлы автоматически не удаляются: актуальный состав указан в manifest. Папка с manifest другой группы не используется. JSON записывается через временный файл и замену. Manifest помечается как незавершённый ещё до чтения списка песен.

## Параметры

```bash
dotnet run --project Utils/BandfixGrabber -- --band "MBV Youth" --output ./export
dotnet run --project Utils/BandfixGrabber -- --chrome /usr/bin/google-chrome --timeout 20
dotnet run --project Utils/BandfixGrabber -- --profile ~/bandfix-profile --site https://bandfix.app
dotnet run --project Utils/BandfixGrabber -- --help
```

`--timeout` задаётся в минутах. Относительные пути считаются от рабочего каталога; `~/` раскрывается. Неизвестные параметры считаются ошибкой.

Для подключения к уже открытому отдельному Chrome:

```bash
google-chrome --user-data-dir="$PWD/Utils/BandfixGrabber/chrome-profile" --remote-debugging-address=127.0.0.1 --remote-debugging-port=9223 https://bandfix.by/app/songs
dotnet run --project Utils/BandfixGrabber -- --cdp http://127.0.0.1:9223
```

`--cdp` допускает только localhost. Если этот профиль уже открыт без порта подключения, закройте его окна и используйте обычную команду запуска утилиты.

Для работы без браузера можно передать действующий Bearer-токен через переменную окружения `BANDFIX_TOKEN`. В этом режиме используется API `https://prod-bandfix-gateway.azurewebsites.net/api`; токен в файлы и консоль не записывается.

Профили и папка `songs` исключены из Git. Для других путей вывода настройте исключения самостоятельно.

## Проверка без входа и сети

```bash
dotnet build Utils/BandfixGrabber/BandfixGrabber.csproj
dotnet run --no-build --project Utils/BandfixGrabber -- --self-test
```

Встроенные проверки используют тестовый HTTP-обработчик и временные папки: страницы и кодирование курсора, дубликаты, удалённые песни, одинаковые названия, Unicode, частичные ошибки, повтор курсора, HTTP 429, обновление токена, переход от гостевой и просроченной сессии к авторизованной. Также проверяются обнаружение прежнего порта Chrome по аргументам процесса, чтение динамического порта и отказ от другого профиля. Это проверяет логику граббера, а не доступность живого сайта или Google OAuth.
